Sobre o Sistema

Objetivo

Monitorar a temperatura de ambientes industriais em tempo real, alertando operadores sobre condições de risco para prevenir acidentes e garantir a segurança operacional.

Tecnologias

ESP32 MQTT HTML5 CSS3 JavaScript Supabase

O ESP32 envia os dados via MQTT para o broker EMQX, que são consumidos pelo frontend e armazenados no Supabase para análise histórica.

Faixas de Segurança

Normal: < 25°C
Atenção: 25°C - 40°C
Crítico: > 40°C
